# 斗兽棋 · Jungle Chess

经典斗兽棋网页版，支持人机对战、双人对战、大模型 AI 对手和 WebRTC 联机对战。

## 在线试玩

👉 **https://shun2007.github.io/dou-shou-qi/**

## 游戏模式

| 模式 | 说明 |
|------|------|
| 🤖 人机对战 | 内置 minimax AI，简单/中等/困难三档难度 |
| 🧠 大模型 AI | 接入通义千问等 OpenAI 兼容大模型，AI 可自主分析局面并使用技能 |
| 👥 双人对战 | 同设备轮流操作 |
| 🌐 联机对战 | 基于 PeerJS WebRTC，创建/加入 6 位房间号，点对点实时对战 |

## 大模型 AI 使用方法

1. 模式选择「大模型 AI」
2. 点击设置 → 大模型设置
3. 填写 API 地址（默认通义千问兼容端点）、API Key、模型名
4. 点击「测试连接」确认可用后保存
5. 开始游戏，蓝方由大模型操控，会自主走棋和释放技能

## 联机对战使用方法

1. 模式选择「联机对战」
2. 房主点击「创建房间」，获取 6 位房间号
3. 对手输入房间号点击「加入房间」
4. 连接成功后自动开始，房主执红方先手

## 技能系统

游戏包含 26 种主动/被动技能，包括突进、背水一战、幻化、点石成金、命运、过河、陷阱、召唤等，每局可在设置中自由开关和配置使用次数。

## 技术栈

- 纯前端 HTML/CSS/JavaScript，无构建依赖
- TensorFlow 风格的 minimax 搜索（内置 AI）
- OpenAI 兼容 API（大模型 AI）
- PeerJS（WebRTC 联机）
- GitHub Pages 部署
